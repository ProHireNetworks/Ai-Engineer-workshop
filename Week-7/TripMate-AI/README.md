
# ✈️ TripMate AI – Multi-Agent Travel Planning Assistant

## Project Overview

TripMate AI is an AI-powered travel planning assistant that generates personalised travel plans based on user preferences, budget, destination, travel dates and interests.

The application uses multiple AI agents coordinated through LangGraph.

## Key Features

- LLM Tool Calling / Function Calling
- Pydantic Structured Outputs
- Agent State Management
- Conditional Routing using LangGraph
- Human-in-the-Loop
- Agent Evaluation and Error Handling
- Retrieval-Augmented Generation (RAG)
- AI Security and Prompt Injection Protection
- Docker and AWS Deployment

## Technology Stack

- Python
- LangChain
- LangGraph
- Groq LLM
- Pydantic
- FastAPI
- React
- ChromaDB
- Docker
- AWS

## Installation

1. Clone the repository.
2. Create a Python virtual environment.
3. Activate the environment.
4. Install dependencies using:

```bash
pip install -r requirements.txt
```

5. Configure environment variables in `.env`.
